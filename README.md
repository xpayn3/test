# Knjiga — 3D book reader

A bookshelf floating in dark space with three public-domain books by Oton Župančič from dLib: *Ciciban in še kaj* (1915), *Ciciban* (1932, illustrated by Nikolaj Pirnat) and the handwritten manuscript. Take a book off the shelf and turn its pages with your finger or mouse.

**Live:** https://xpayn3.github.io/test/

- Tap a book on the top shelf to take it out; tap or swipe the cover to open it.
- Drag or tap a page to turn it; the slider under the book jumps between poems.
- Works on touch screens and tablets; everything (3D engine, font, scans, sounds) is in this repository, so it runs offline too.

This is a static site published from the `main` branch with GitHub Pages. The working project lives in a separate folder; this repository holds only the files the website needs.
